# Playbooks-BITGET

GetAgent Playbook packages for Bitget, with the research behind them.

| path | what |
|---|---|
| `playbooks/<name>/` | the package that is uploaded: `manifest.yaml`, `backtest.yaml`, `README.md`, `src/` |
| `research/<name>/` | scripts and notes that justify the package's design |
| `docs/` | operational notes such as the draft cleanup checklist |

Upload only the package directory's files (`manifest.yaml backtest.yaml README.md src`), never `__pycache__`.
